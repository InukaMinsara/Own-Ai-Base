A web application is software accessed through a web browser.
HTML describes the structure of a web page.
CSS describes presentation and layout for web content.
JavaScript adds behavior and interactive logic to web pages.
A frontend is the part of an application that users directly interact with.
A backend provides server-side logic, data access, authentication, or other services.
A REST API commonly exposes resources through HTTP methods and structured responses.
JSON is a text format commonly used to represent structured data.
A request sends information from a client to a server.
A response carries a result from a server to a client.
A database query asks a database to retrieve or modify information.
SQL is a language commonly used to work with relational databases.
A table organizes relational data into rows and columns.
A primary key identifies a row within a table.
A foreign key represents a relationship between tables.
An index can accelerate certain database lookups by maintaining an additional searchable structure.
Git is a distributed version control system.
A repository stores project files and version history.
A commit records a set of changes in version control.
A branch is an independent line of development.
A merge combines changes from different lines of development.
A pull request is a proposed set of repository changes for review and integration.
A dependency is an external component required by a software project.
A package manager installs and manages software dependencies.
A virtual environment isolates Python project dependencies.
A compiler translates source code into another representation.
An interpreter executes code through a runtime system.
A build process transforms source files into deployable or executable outputs.
Continuous integration automatically runs checks when project changes are submitted.
Deployment makes a software application available in a target environment.
